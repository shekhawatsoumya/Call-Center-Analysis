# Call Center Analysis

## Project Overview
This project analyzes call center performance data to evaluate agent productivity, customer satisfaction, and call handling efficiency. The analysis provides insights into operational strengths and areas for improvement.

## Data Source
The dataset used in this analysis is sourced from Kaggle.

## Data Cleaning
Data cleaning was performed using Power Query Editor in Excel to prepare the raw data for analysis, ensuring data quality and consistency.

## Analysis
The analysis was conducted using Excel and includes the following key components:

### Executive Summary
- Total calls handled: 5,000
- Calls resolved: 3,646 (resolution rate: ~73%)
- Number of agents: 8

### Agent Productivity
- **Top Answerer**: Jim handled 536 calls
- **Most Resolved**: Jim resolved 483 calls, followed by Becky (463)
- Agents show strong resolution efficiency, with most maintaining high resolved-to-answered ratios

### Customer Satisfaction (CSAT)
- Average satisfaction rating: 3.3 - 3.4
- **Peak Performers**: Dan and Martha (3.4 rating)
- **Areas for Improvement**: Joe (3.2 rating) requires targeted coaching

### Call Topics & Volume
- Main topics: Admin Support, Contract-related, Payment-related, Streaming
- High-volume categories: Streaming and Payment-related issues
- Call volumes are distributed relatively evenly across agents

### Key Recommendations
- Investigate Joe's performance to improve satisfaction ratings
- Reward top performers like Jim, Dan, and Martha
- Review processes for Streaming and Payment issues to potentially reduce call volume through self-service options

## Project Structure
- **Raw Data/**: Contains the original dataset (`excel_callcenter.xlsx`)
- **Clean Data/**: Contains the cleaned data (`excel_callcenter(Cleaned Data).xlsx`)
- **Result/**: Includes the analysis dashboard (`Call Center Dashboard.png`)
- **Description/**: Contains detailed analysis report (`Call Center.txt`)

## Viewing the Results
To view the analysis results:
1. Open the cleaned data file in Excel
2. Refer to the dashboard image in the Result folder for visualizations
3. Read the detailed report in Description/Call Center.txt

## Tools Used
- Excel (for data cleaning with Power Query and analysis)
